# 스토어 등록 체크리스트 (Google Play / App Store)

배포 완성품을 스토어에 올리기 위한 준비물과, 데이터 항목을 우리 앱의 실제 동작에 맞춰
정리한 답변표입니다. `[대괄호]`는 운영자가 채웁니다.

---

## 0. 공통 준비물

- [ ] 앱 아이콘 — 완료 (`mobile/assets/icon-1024.png`)
- [ ] **개인정보처리방침 URL** (필수) — `docs/PRIVACY_POLICY.md` 를 채워 웹에 게시
      (예: 배포 서버에 `/privacy` 정적 페이지로 호스팅)
- [ ] 스크린샷 — 실기기에서 촬영 (가입 화면 / 홈 / 통화중·안전번호 화면 권장)
- [ ] 지원 연락처 이메일: [이메일]
- [ ] 카테고리: **커뮤니케이션(Communication)**

### 앱 설명 초안 (한국어)

**짧은 설명(80자 이내):**
> 개인정보 없이 아이디만으로. 종단간 암호화 음성통화 앱.

**전체 설명:**
> SecretCall 은 통화에만 집중한 종단간 암호화(E2EE) 음성통화 앱입니다.
>
> • 개인정보 없이 가입 — 이름·전화번호·이메일 없이, 발급받은 아이디와 1회용 코드로 시작
> • 상대 아이디만 알면 통화 — 연락처 접근 없음
> • 종단간 암호화 — 통화 내용은 두 기기 사이에서만 복호화되며 서버는 열람 불가
> • 안전번호 확인 — 통화 중 안전번호를 비교해 도청·중간자 공격을 차단
> • 문자 기능 없음 — 오직 통화

### 데이터 보안(Data safety) 양식 답변
우리 앱 기준 정확한 답:

| 질문 | 답 |
|------|----|
| 데이터를 수집/공유하나요? | **예** (아래 항목만) |
| 수집: 앱 활동/기기 ID 등 | **없음** (광고 ID·기기 식별자 미수집) |
| 수집: 앱 기능용 식별자 | **사용자 ID**(운영자 발급), **푸시 토큰** |
| 데이터 전송 시 암호화 | **예** (TLS) |
| 사용자가 삭제 요청 가능 | **예** (운영자에게 계정 삭제 요청) |
| 통화 콘텐츠(오디오) 수집 | **아니오** (종단간 암호화, 서버 미보관) |
| 위치/연락처/사진 | **아니오** |
| 제3자 공유 | 푸시 전달을 위한 FCM(Google) — 앱 기능 목적 |

### 콘텐츠 등급 설문
- 폭력/성인/도박 요소 없음 → 전체이용가 예상
- 사용자 간 통신(음성) 있음 → 해당 문항 "예"

### 기타
- [ ] 타깃 API 레벨 최신 요건 충족(빌드 시 자동)
- [ ] 앱 서명(Play App Signing) 사용
- [ ] `.aab` 업로드 (`gradlew bundleRelease`)

### 필수 자산

### App Privacy(개인정보 라벨) 답변
| 데이터 유형 | 수집? | 연결/추적 |
|-------------|-------|-----------|
| 연락처 정보(이름·이메일·전화) | 아니오 | - |
| 사용자 콘텐츠(오디오 등) | 아니오(E2EE) | - |
| 식별자 — User ID | 예 | 앱 기능용, **추적 아님** |
| 식별자 — 기기ID/광고 | 아니오 | - |
| 위치/연락처/사진 | 아니오 | - |
| 사용 데이터/진단 | [운영자 정책에 따라] | - |
- App Tracking Transparency(ATT): 광고·추적 미사용 → 해당 없음

### 수출 규정(암호화) — 중요
- 앱이 암호화를 사용하므로 제출 시 **Export Compliance** 질문에 답해야 합니다.
- 표준 암호화(HTTPS/WebRTC 등)만 사용하고 별도 암호화 기능을 "제공"하는 앱은 대개
  면제 대상이나, **E2EE 통화**는 자가분류(자기평가)가 필요할 수 있습니다.
- 간편 처리: `Info.plist` 에 아래를 넣고, 실제 해당 여부를 반드시 확인하세요.
  ```xml
  <key>ITSAppUsesNonExemptEncryption</key>
  <false/>
  ```
  > ⚠️ 이 값은 "면제되지 않는 암호화를 쓰지 않음"을 뜻합니다. E2EE 앱은 상황에 따라
  > `true` + 연간 자가분류 보고가 필요할 수 있으니, Apple 문서/법률 검토로 확정하세요.

### 심사 메모(리뷰어용 노트) 초안
> 이 앱은 개인정보를 수집하지 않으며(운영자 발급 아이디만 사용), 음성통화는 종단간
> 암호화됩니다. 테스트용 아이디/등록코드: [발급해 제공]. 마이크 권한은 통화에만 사용됩니다.

## 3. 배포 전 최종 점검

- [ ] `mobile/src/config.ts` 의 `PROD_HTTP`/`PROD_WS` → 실제 도메인(https/wss)
- [ ] 서버 `.env` 의 `ADMIN_KEY`, `TURN_STATIC_SECRET` 강력한 값으로 설정
- [ ] TURN 서버 동작 확인 (`docs/DEPLOY.md`)
- [ ] 푸시(FCM/APNs) 실기기 수신 확인 (`docs/PUSH_SETUP.md`)
- [ ] 개인정보처리방침 URL 접속 가능
- [ ] 두 실기기(서로 다른 망)에서 통화 연결 + 안전번호 일치 확인
